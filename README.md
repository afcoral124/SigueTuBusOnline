# SigueTuBusOnline: Sistema IoT para el Seguimiento y análisis del estado del Transporte Público
Sistema que permite el envío de datos GPS del módulo ESP8266 a un servidor web, que imprime con la API de Google Maps, la ubicación del módulo. Contiene un gestor de información de usuarios, conductores y vehículos. Creado con PHP + HTML + API de Google Maps.
